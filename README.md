# Premium Developer Portfolio

A minimal, high-performance developer portfolio built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Three.js**.

Inspired by modern architectural brutalism and editorial minimalism, featuring high-contrast chapter pacing, chamfered cut-corner geometry, blueprint corner brackets, and interactive 3D WebGL visualizations.

---

## ✨ Features

- **Floating Glassmorphic Capsule Nav**: Centered floating pill with active section scroll-spy, backdrop blur, and responsive mobile drawer.
- **Dual-Mode Hero Switcher**: Seamlessly toggles between a high-resolution professional portrait and an interactive Three.js 3D WebGL metallic aura canvas.
- **Alternating Thematic Contrast**: Strategic rhythm between soft slate paper surfaces (`#eef2f6`) and deep midnight navy canvases (`#0b1026`).
- **Architectural Blueprint Styling**: Custom chamfered cut corners (`clip-path`) and technical corner brackets (`┌ ┐ └ ┘`).
- **3-Pillar Technical Arsenal**: Categorized skill chips with proficiency levels and verified production indicators.
- **Featured Projects with Architecture Modal**: 2-column responsive grid with category filtering, image hover zoom, and detailed lightbox modal.
- **Competitions & Achievements**: Hackathon Grand Prize winner spotlight with golden champion badge, metadata table, and interactive team photo carousel.
- **Fully Responsive & Accessible**: Optimized for desktop (1440px), tablet, and mobile (390px) viewports with WCAG AA focus rings.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

## ✏️ Customizing Your Content

All data is centrally managed and typed in [`src/data/portfolioData.ts`](./src/data/portfolioData.ts):

- **Personal Info**: Update name, bio, status, location, and quick numerical stats.
- **Skills**: Add or modify tech stacks across the 3 pillars.
- **Projects**: Add project titles, categories, images, summaries, and GitHub/Live URLs.
- **Education & Achievements**: Update academic degrees and hackathon/award highlights.
- **Contact & Socials**: Configure email, LinkedIn, GitHub, and Twitter/X links.
